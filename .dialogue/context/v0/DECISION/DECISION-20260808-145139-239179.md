Decision (design): moved Mixcloud/Spotify/Tidal playlist and show enrichment out of the production build path (scripts/enrich-shows.ts, scripts/enrich-playlists.ts) and into a new scheduled GitHub Action (.github/workflows/shows-refresh.yml), mirroring the existing next-show-refresh.yml pattern. `pnpm run build` is now `astro build` only, so production builds no longer call third-party APIs and are deterministic/reproducible. Added vercel.json to pin build/install/output settings (framework astro, pnpm run build, pnpm install --frozen-lockfile, outputDirectory dist) in VCS instead of relying on Vercel dashboard defaults. This was done alongside a broader refactor addressing docs/2026-08-08-claude-code-review.md: fixed the platform.ts compile error and redundant non-null assertions, added warn-on-failure logging and a shared scripts/lib/enrich-utils.ts, folded tracklists into shows.generated.json to remove the fuzzy mergeShowsWithSources join, routed homepage sorting through the tested sortShows, moved next-show HTML parsing into src/lib with fixture tests, added a shared Normalizer<TSource, TApiData, TResult> type for provider normalizers, and expanded the opt-in remote next-show test suite to cover failure/fallback behavior. Shipped as PR #33 (fix/claude-review-findings -> main).
